    常见问题

    FAQ
    运行需要管理员权限吗？

    改显卡名、CPU 亲和性、电源方案这些核心功能需要管理员权限。非管理员启动时软件会自动 UAC 提权重启，标题栏的徽章会实时显示当前权限状态。

    显卡名称修改安全吗？会不会损坏系统？

    只改注册表里的显示名称（DeviceDesc），不动驱动、不碰系统文件，修改前会自动备份原值，随时可以一键恢复。任务管理器 / 设备管理器里的显示名需重启后完全生效。

    网络加速改了系统设置，能还原吗？

    可以。打开「改动记录」页，程序做过的全部持久改动都在台账里：DNS、Nagle、网卡省电、显卡名、启动项……支持单条还原或一键全部还原，原本不存在的值还原时直接删除，并自动回读校验。

    用这类工具会被游戏封号吗？

    工具箱只用 Windows 公开接口（注册表 / powercfg / netsh / CIM），不装驱动、不 hook 协议栈、不注入游戏进程、不读写游戏内存，与外挂 / 作弊器有本质区别。

    系统要求和安装方式？

    Windows 10 / 11（64 位）。zip 压缩包约 26 MB，解压即用，无需安装；首次启动会自动请求管理员权限，属正常行为。
